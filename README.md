# PartyChat Accounting V2

A local Mac-friendly desktop accounting/party ledger built with Python and Tkinter.

## Run on macOS

```bash
git clone https://github.com/snayanam/PartyChat-Accounting.git
cd PartyChat-Accounting
python3 PartyChat_Accounting_V2.py
```

The app creates its local database at `~/PartyChat Accounting/partychat_v2.db`.

Features include parties, receivables/payables, due/settled status, projects, project members, consolidated project ledger, backups, restore, and CSV export.
